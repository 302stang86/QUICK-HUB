# FDEC Quick Hub

Employee portal hosted on GitHub Pages, with Firebase for employee sign-in and application data. The hub opens from the root `index.html`.

Keep GitHub Pages configured for the existing root folder so the employee hub stays at its current address.

## Existing games

SwitchBack TD runs from `switchback/index.html` with its separate public, anonymous leaderboard. Tank Battle and Gladiator Duel use their existing root-level game files.


## AI Quote Assistant

Open `ai-quote-assistant/index.html` from the manager/admin home card to prepare reviewed quote scopes from technician notes and PDF reports. The section includes manual drafting, editable findings, source references, optional device saves, draft downloads, selected wording exports, and transfer to the existing sprinkler and fire alarm quote tools. Live AI analysis requires activating the included secure Firebase function; see [AI Quote Assistant setup](ai-quote-assistant/SETUP.md). The interface shows setup status until the authenticated backend connection is ready.
