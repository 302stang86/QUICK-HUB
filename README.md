# FDEC Quick Hub

Employee portal hosted on GitHub Pages, with Firebase for employee sign-in and application data. The hub opens from the root `index.html`.

Keep GitHub Pages configured for the existing root folder so the employee hub stays at its current address.

## Existing games

SwitchBack TD runs from `switchback/index.html` with its separate public, anonymous leaderboard. Tank Battle and Gladiator Duel use their existing root-level game files.
